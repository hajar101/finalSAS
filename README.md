# 🦇 SAS Progress Console

Un petit projet JavaScript pour suivre la progression des apprenants.

📚 **JavaScript • Node.js • Readline**

### Ce que ça fait

* 👤 Ajouter des apprenants
* 📊 Suivre leur progression
* 🔎 Rechercher et filtrer
* 📈 Trier les résultats
* 🖥️ Afficher un tableau de bord

> Petit projet, grandes lignes de code. 🖤
